# 天気予報フィード

気象庁が発表する天気予報を、一次細分区域（全国142地点）ごとに iCal・RSS・JSON で配布しています

公開サイト: https://nidoneru.github.io/jma-weather-feed/

## 配布形式

- **iCal**（`ical/<地域コード>.ics`）: 日単位の終日イベント。Google カレンダーなどに URL で登録すると、予報がそのままカレンダーに並びます。webcal リンクも同じファイルです
- **RSS**（`rss/<地域コード>.xml`）: 1日1件、7日分。OPML（`feeds.opml`）で全地点をまとめて取り込めます
- **JSON**（`json/<地域コード>.json`）: 独自スキーマ。日付・天気・降水確率・最高/最低気温・風を日ごとに並べます

どの形式も、短期予報（今日〜明後日）と週間予報を統合した7日分です（表示は短期優先）。

## 仕組み

- `generate.py` が気象庁の予報 JSON（府県予報区ごと）を取得し、区域ごとに再構成します
- 天気の文言は天気コード表（`data/weather_codes.json`）から組み立てます。気温の地点と区域の対応は `data/points.json`、週間予報の区域の対応は `data/weekly_areas.json` にあります
- GitHub Actions が1日3回（5:45／11:45／17:45 JST）生成し、gh-pages ブランチへ公開します。生成に失敗した回は、公開物は前回のまま残ります

## 出典と免責

気象庁の天気予報データを加工して作成しています。データは[気象庁ホームページ](https://www.jma.go.jp/)で発表されたものです。

このサイトは、個人が運営する非公式なものです。予報の正確性は保証しません。防災など重要な判断には、必ず気象庁の公式情報を確認してください。
